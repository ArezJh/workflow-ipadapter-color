# workflow-ipadapter-color
Custom ComfyUI Workflow: IPAdapter + Color Palette Control 🎨

Hey everyone! I’ve been working on a custom ComfyUI workflow where I combine IPAdapter for style transfer with a node that helps me define and preserve a specific color palette throughout the generation process.

The main goal is to keep the generated image stylistically consistent while respecting a target palette, aiming for more visually harmonious and intentional results.

:test_tube: The workflow is still evolving, so I’d love to hear any suggestions on how to improve it — especially in making the model respond more accurately to the color palette without losing the intended style.

If you’ve tried something similar or know any tips for better color control in ComfyUI, I’m all ears!

Happy to share screenshots or the workflow file if anyone’s interested :raised_hands:
